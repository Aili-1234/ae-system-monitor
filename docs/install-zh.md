# AE System Monitor 1.4.0

一个塞进 After Effects 的停靠面板，只回答一件事：**AE 的磁盘缓存还够不够用，什么时候会撞线，撞线前能不能先替你存一次盘。**

不是独立软件，装完在 AE 的「窗口 > 扩展 > System Monitor」里出现，随 AE 一起开关。

![面板](截图-面板.png)

---

## 它显示什么

| 这一格        | 意思                                               |
| ---------- | ------------------------------------------------ |
| 已用 / 上限    | AE 磁盘缓存现在占多少、配额是多少（上限从 AE 首选项里读，没有公开 API）        |
| **余量**     | 磁盘可用 −（上限 + 10 GB 安全垫）。**负数就是 AE 会弹「磁盘空间不足」的时刻** |
| 增速 / 还能撑多久 | 按最近 2 小时的真实增速，推算几天后撞线                            |
| 其他版本缓存     | 机器上别的 AE 版本留下的缓存各占多少（只统计、不删除）                    |
| 内存         | 当前 AE 进程的内存占用与曲线                                 |
| 崩溃保护       | 检测到内存飙升、缓存余量转负、改动长时间未保存时，替你静默存一次盘                |

## 支持环境

- **Windows + After Effects CC 2017（14.0）及以上**，一直覆盖到 2026 版。
- macOS 理论上可用（脚本里有对应分支），但**没有实测过**，如果你在 Mac 上试装了，请自己核对一遍。
- 不需要装 Node、不需要联网、不需要管理员权限（写的是当前用户目录和 HKCU 注册表）。

## 安装（三步）

1. **解压**整个压缩包到任意位置（例如桌面）。这些文件必须保持在一起（缺一个面板就起不来）：`install.bat`、`CSXS\`、`js\`、`css\`、`jsx\`、`index.html`。
2. **双击 `install.bat`**。它做两件事：把文件复制到 `%APPDATA%\Adobe\CEP\extensions\AESystemMonitor`，并给 CSXS.6~12 打开 `PlayerDebugMode`（没有 Adobe 签名的小面板必须打开这个开关才能被 AE 加载）。看到 `[OK] Installed successfully` 即成功。
3. **完全退出 After Effects 再重开**（不是关面板，是退出程序）。菜单 `窗口 > 扩展 > System Monitor` 打开面板，拖到顺手的停靠位置。

> 不想双击 bat 的话，手动安装等价于：把整个文件夹复制到 `%APPDATA%\Adobe\CEP\extensions\AESystemMonitor`，然后注册表 `HKEY_CURRENT_USER\Software\Adobe\CSXS.11`（按你的 CEP 版本，6~12 都写一遍也没关系）新建字符串值 `PlayerDebugMode` = `1`。

## 卸载

双击同目录的 `uninstall.bat`，删掉面板文件夹即可（`PlayerDebugMode` 注册表项故意保留，别的未签名面板可能还要用）。重开 AE 生效。

## 第一次打开要调的两件事

打开面板右上角的齿轮（设置）：

1. **崩溃保护**：默认是开的，自动保存间隔沿用 AE 自己的设置。建议先只留「风险升高时自动保存」这一项，跑一周看看日志，再决定要不要更激进。
2. **定时提醒**（喝水/起身/远眺）：默认开，不需要就关掉。

**它到底有没有替你存过盘**：设置里打开「记录每次保存（含失败原因）」，日志写在  
`%LOCALAPPDATA%\AESystemMonitor\saves.log`，每行一条：时间 / 成败 / 原因 / 耗时 / 失败原因 / 工程路径。面板的崩溃保护卡里也会显示最近 5 次。关掉开关就不再写文件。

## 数据与隐私

- **不联网**。整个面板没有任何 HTTP 请求、没有遥测、没有更新检查。
- 只读三样东西：AE 的首选项文件（拿缓存上限）、缓存目录里的文件大小、系统内存与磁盘可用量。
- 只写三样东西：面板自己的配置（`localStorage`）、上面那份保存日志、以及你点「自动保存」时由 AE 自己写出的工程副本。

## 常见问题

**菜单里找不到 System Monitor**

1. 确认文件夹在 `%APPDATA%\Adobe\CEP\extensions\AESystemMonitor`（`index.html` 就在这一层）。
2. 确认注册表 `HKCU\Software\Adobe\CSXS.11` 的 `PlayerDebugMode` 是字符串 `1`。
3. AE 必须**完全重启**；只关面板不算。

**面板能开，但数字都是 `--`**  
`manifest.xml` 里 Node 集成被关掉，或 CEP 沙箱拦住了文件读取。重装一次、重启 AE 再看。若仍然为空，看一眼菜单 `窗口 > 扩展` 里是不是有两个同名项（旧版本残留）。

**余量是负数怎么办**  
不用等 AE 报错：要么把缓存上限调小（点面板上的「上限」那个数字就能改），要么把 AE 的缓存盘指向别的盘，要么清一次 `Disk Cache - *.noindex` 目录。

**它会不会拖慢 AE**  
空转 3 秒一次轻量刷新；**AE 正在渲染时自动降到 12 秒一次**；面板不可见降到 30 秒；数值没变就不重绘；磁盘读数 30 秒才真正取一次。渲染期心跳超时也从 3 秒缩到 1.5 秒，宁可少一次读数也不打断渲染。

## 它做不到什么（先说明白）

- **AE 崩了它一起消失**，没有「崩溃后抢救」这种能力。
- 没有「即将崩溃」的 API，只能靠内存、余量、改动未保存这类统计信号提前一步。
- **面板关掉就不保护**。想要保护就把面板留着（可以折叠成窄条，占 96×132 像素）。
